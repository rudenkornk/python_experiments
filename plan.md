## 9.1. Чтение из файла и запись в файл

[Блокнот и исходные файлы](https://edu.hse.ru/mod/folder/view.php?id=502734)

| Подтема | Как объясняется в блокноте |
|---|---|
| Кодировка и форматы | TXT и CSV читаются как текст. Чтобы получить таблицу, строки CSV ещё нужно разобрать. |
| Открытие | В `with open(...) as infile` вызывают `print(infile)` и видят описание файла вместо его содержимого. Затем явно указывают `mode='r'` и `encoding='UTF-8'` и читают строки циклом `for line in infile`. |
| Переносы строк | Сравнивают `print(text)` с отображением `text` в ячейке: во втором случае видны символы `\n`. Чтобы собрать текст в одну строку и не склеить слова, используют `line.strip() + ' '`. |
| Запись | Через `print(..., file=outfile)` записывают текст в `info.txt` и проверяют, где появился перенос строки. Открывают тот же файл с `'w'`, затем с `'a'`: в первом случае старый текст исчезает, во втором новый дописывается. |

## 9.2. Частые слова в «Капитанской дочке»

[Блокнот и исходные файлы](https://edu.hse.ru/mod/folder/view.php?id=502741)

Можно ли по самым частым словам понять, о чём книга?

| Подтема | Как объясняется в блокноте |
|---|---|
| Подготовить текст | Читают `dochka.txt` и разбивают текст по пробелам.  У получившихся «почти слов» остаются знаки препинания, которые нужно убрать перед подсчётом. |
| Посчитать частоты | `create_dict()` строит словарь `слово → число употреблений`.  Сначала проверяют результат вручную на короткой фразе, затем обрабатывают всю повесть.  Чтобы посмотреть только часть словаря, пишут `print_dict()`. |
| Найти самые частые слова | Сортировка пар `(слово, частота)` из `items()` даёт алфавитный порядок.  Переставляют элементы пары, сортируют по убыванию и выводят первые десять записей. |
| Убрать стоп-слова | В начале списка оказываются «и», «в», «не».  Фильтруют слова по списку стоп-слов, заново считают частоты и сравнивают результаты. |
| Сохранить результат | При печати кортежей в `words.txt` в файл попадают скобки.  В `words.csv` слово и частоту записывают отдельными полями, чтобы файл можно было открыть как таблицу. |
| Дополнительно: разобрать равенство частот | Частоты должны идти по убыванию, а слова одной частоты — от А до Я.  Один `reverse=True` разворачивает порядок по обоим элементам пары. |

## 9.3. Дневные и ночные температуры в CSV

[Блокнот и исходные файлы](https://edu.hse.ru/mod/folder/view.php?id=502745)

| Подтема | Как объясняется в блокноте |
|---|---|
| От текста к таблице | Содержимое `temperature.csv` представляют сначала одной строкой, затем списком строк. После `line.split(';')` каждая запись становится списком из двух полей: дневная и ночная температура. |
| От строк к числам | Сначала применяют `int()` к каждому полю отдельно, затем используют `list(map(int, day_list))`. |
| Среднее по столбцам | Считают суммы дневных и ночных температур отдельно и делят каждую на число дней. |
| Округление | Сравнивают усечение через `int()`, округление вверх через `math.ceil()` и округление через `round()`. При точной половине `round()` выбирает ближайшее чётное: `round(25.5) == 26`, но `round(14.5) == 14`. |
